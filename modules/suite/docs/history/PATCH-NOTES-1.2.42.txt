# Suite 1.2.42 — consolidated improvement pass

Changes after public Suite **1.2.41**. Includes the MapMemory1, MemoryAudit1, MemoryAudit2 and Improve1 passes, now aligned to the real public versions. Internal draft numbers do not represent separate public releases. Website source is **2.7.4**.

## Server Essentials Suite 1.2.42

- Decode startup map exports without loading world chunks or reconstructing saved entities, block entities, decorations and mod data. Missing height metadata uses a detached terrain scan.
- Reduce export chunk pools, release their arrays when export finishes, and avoid retaining large overview buffers in shared pools. Add export cleanup and memory diagnostics.
- Preserve the current map and pending terrain changes after database read failures; avoid silently falling back to the heavier world loader.
- Bound and expire PacketGuard diagnostic identities; clear disconnected-player and stopped-service state.
- Limit Mod DB verification to 512 pending/in-progress requests, 1,024 cached results and an estimated 64 MiB. Prioritize installed baselines; cancellation releases reservations and prevents late publication.
- Explain substantial GC fragmentation when the post-GC memory floor is stable or falling.
- Complete waiting logger requests with errors when workers stop or migrations fail. Reject new requests on stopped workers and make shutdown repeatable.
- Show failed SQLite searches as errors instead of empty results.
- Retain and retry dirty-map journal rows after write failures. Bound append batches and combine burst wakeups.
- Make dirty-map snapshot generations and export acknowledgements atomic; protect newer edits and preserve state after failed compaction.
- Serialize admin snapshot capture and persistence so an old save cannot clear or overwrite a newer request.
- Load inventory snapshot headers at startup and fetch item data only when requested, reducing memory retained for historical players.
- Release snapshot payloads only after successful commits; preserve unsaved data for retry and unloaded historical data on disk.
- Validate all snapshot items and backpack capacity before restoring an inventory; restore bags before their contents.
- Avoid repeating retention SQL for every historical player on every save.
- Reject invalid and overflowing moderation durations.
- Preserve map opt-outs when their saved file is unreadable, malformed or incompatible; hide coordinates until privacy state is recovered.
- Commit waypoint changes only after successful saves; protect unreadable and unsupported stored data.
- Prevent stale public map and activity refreshes from publishing after settings or privacy changes.
- Clear WebPanel diagnostic snapshot caches when the listener stops; paused cold requests do no snapshot work.
- Improve role draft controls and unsaved-change navigation protection. Prevent overlapping or outdated player-role, console and database responses.
- Dispose Shift+L resources when closed, stop profiler polling, ignore late replies and unregister temporary waypoint dialogs.
- Align project, assembly, runtime build identity, Windows/Linux build scripts and packages to **1.2.42**. Enforce exactly the next public patch for edited published mods.
