# Discord slash commands

Discord Integration registers guild-scoped slash commands in the configured Discord guild.

## Player information commands

These are read-only and available to Discord members with permission to use application commands:

- `/players` - online player count and names
- `/serverinfo` - server name, world, player count, in-game date, bridge status
- `/date` - current Vintage Story date and hour
- `/discord` - configured invite URL
- `/rules` - configured rules text/link
- `/help` - lists commands; staff commands appear only for recognized staff

## Staff-only commands

Staff authorization is granted when either:

1. the member has one of `Commands.StaffRoleIds`, or
2. `Commands.AllowDiscordAdministrators` is enabled and the member has Discord Administrator.

Commands:

- `/announce message:<text>` - broadcasts a notification in game
- `/kick player:<name> reason:<optional>` - disconnects an online player
- `/allowcharsel player:<name>` - allows the player to reopen Vintage Story character selection one additional time
- `/whitelist action:<Add|Remove> player:<name>` - adds or removes a player using Vintage Story's native whitelist command
- `/ban player:<name> duration:<30m|6h|3d|2w> reason:<optional>` - temporary ban delegated to Server Essentials Core
- `/unban player:<name>` - delegated to Server Essentials Core
- `/mute player:<name> duration:<30m|6h|3d|2w|permanent> reason:<optional>` - delegated to Server Essentials Core
- `/unmute player:<name>` - delegated to Server Essentials Core

Every staff command attempt, including denied attempts, is written to the configured Admin Audit route.

## Discord bot authorization

The bot installation must include the `applications.commands` OAuth2 scope in addition to the bot scope. Guild-scoped commands are overwritten from this module's command definition when the Discord client becomes ready.

## Account linking (0.3.0 transport)

When `Commands.EnableLinkCommands` and `Linking.Enabled` are true in the unified Discord module:
- `/link <code>` - submit the one-time code generated by `/discordlink` in Vintage Story
- `/linkstatus` - show the Discord user's current Vintage Story link
- `/unlink` - remove the Discord user's current link

These responses are ephemeral. Link state, one-time codes, and persistent PlayerUID mappings are owned directly by this unified Discord module.

## Restart controls

When Discord staff commands are enabled, `/restart` is restricted to configured staff roles (or Discord administrators when that option is enabled).

- `/restart action:Status` — show manual and automated restart state.
- `/restart action:Schedule minutes:<1-1440> reason:<optional>` — schedule a graceful restart.
- `/restart action:Restart now reason:<optional>` — request an immediate graceful restart.
- `/restart action:Cancel manual restart` — cancel the pending manual restart/shutdown timer.
- `/restart action:Skip next automated restart` — skip the next UTC scheduler occurrence.

The Suite remains the restart authority. Discord only sends an authenticated staff request over the existing Suite event bus.


## Restart controls

Restart control is separately opt-in with `Commands.EnableRestartCommands` (default `false`). Authorized staff can use `/restart` with the actions `status`, `schedule`, `now`, `cancel`, or `skipnext`. The command delegates to the Server Suite restart service and never implements a second scheduler inside the Discord module.
