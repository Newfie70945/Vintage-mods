# Modules and provenance

The regular mods use original author source restored from the uploaded CENTER1 archive. Versioned archive directory names were replaced with stable module names; manifest versions are authoritative.

- `modules/suite`: original Suite 1.2.43 source with the current 1.2.52 performance timeline and attribution improvements plus UID-targeting, post-builder and console fixes ported onto it.
- `modules/motd`: original MOTD 2.1.6 source with the current feed formatter and all-tab normalisation improvements preserved.
- `modules/anticheat-client`: 1.1.28.
- `modules/chatguard`: 2.1.4.
- `modules/discord-link`: 1.0.13.
- `modules/player-list`: 1.1.2.
- `modules/shared`: shared storage source linked by Suite and ChatGuard.
- `modules/optimizer`: 0.5.0-preview continues the reconstructed profiling project with guarded API patches. It is experimental and was not recovered from this archive.

The standalone website, Website Connector project and ModDB descriptions are deliberately excluded at the owner's request. The recovered upload and excluded files are kept as local backups outside the repository.

Obsolete module changelogs have been removed; Git history preserves them. The root CHANGELOG.md, README and modules/manifest.json describe the active release.
