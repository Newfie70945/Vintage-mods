Newfie’s Server Essentials Suite

A connected administration workspace for your Vintage Story server, in game and in the browser.

One Suite. Two ways to run your server.

Keep investigations, configuration and routine administration together. The in-game Shift+L interface gives staff quick access while playing; the webpanel gives them room to work from a desktop or phone.

Enable the features your community needs and configure access for your staff. The core Suite runs on the server; installing the matching build on a staff client enables the in-game interface.

What is new in this build?

  • Roleplay-name compatibility: Shift+L online-player actions use stable player UIDs rather than visible names. This addresses the account/roleplay-name mismatch reported with Simple Roleplay Nametag Updated. Players sharing a displayed name remain separate picker entries.
  • A clearer MOTD writing workflow: news and update posts inserted through the webpanel use consistent title, date, body and separator formatting. Plain text is safely escaped, and simple dash/star lists become bullets.
  • Console fix: /nsefeatures now replies correctly when run from the server console.
  • Companion MOTD refresh: Newfies Community MOTD 2.1.6 improves feed hierarchy and spacing, preserves owner-written VTML, shows explicit UTC timestamps for Discord posts and honours the local/Discord merge setting. Install the companion update for these in-game changes.

OreShield: optional beta protection

OreShield is off by default. Its ore-visibility protection is functional, but still needs bug fixes and performance polishing. Test it with your mining, skill and world-generation mods before enabling it on a busy server.

Anti-cheat tools support investigation; they do not guarantee that every modified client or exploit will be detected.

Get started

  1. Back up first. Keep a current world backup and a copy of your configuration.
  2. Install one Suite ZIP on the server. Remove the older Suite ZIP so two copies cannot load together.
  3. Start once to generate configuration. Review the files in ModConfig and run /nsefeatures list to check feature gates.
  4. Choose your workspace. Install the same Suite build on staff clients for Shift+L, or configure the webpanel listener and sign in with an authorised account.
  5. Test permissions and changes. Use a test account, then enable only the integrations and protection modules you need.

Build target: Vintage Story 1.22.7 / .NET 10. Check the release’s game-version tags before upgrading your server. Core Suite installation is optional for ordinary clients.

Companion mods & website connection

  • Newfies Community MOTD: a separate universal mod for the join screen, server information, news and update pages. Install it on the server and clients that use its GUI. The Suite can manage its content through the MOTD editor.
  • Player List, Discord Link and Client Integrity: separate companion mods with their own installation requirements and versions. Install only the companions you plan to use.
  • Website Connector: a separate server-side bridge for a separately hosted community website. The public website, connector listener and Suite webpanel listener are distinct services; configure their origins and ports accordingly.
  • Existing command providers: the Suite avoids claiming conditional commands already registered by other mods and provides Suite alternatives under /nse where supported. Check command ownership before enabling overlapping essentials features.

A note about compatibility

The roleplay-name picker fix does not require a hard dependency on the roleplay mod: actions use the account UID while the visible name remains a label. This does not add roleplay-name display controls to the separate Player List mod.

Heavily modded servers need server-specific testing. Tune anti-cheat movement profiles for mounts and skills, test OreShield with mining perks, and verify any generated patches against the installed mod versions.
