Newfies Community MOTD

A branded welcome screen, readable news feed and server information hub inside Vintage Story.

A welcome screen that stays useful

Give players one place to find your server’s introduction, rules, news, recent changes and useful links. Newfies Community MOTD is a native in-game information hub, with configurable branding and separate pages instead of one long wall of text.

News & updates, easier to read

  • Clear hierarchy: page introductions, larger post titles, quieter author/date details, more breathing room and subtle dividers between remote posts.
  • Your content stays yours: owner-written VTML is preserved without an extra generic “Server Announcement” or “Server Update” heading wrapped around it.
  • Readable feed details: important posts remain marked, unread-post identifiers are preserved, and Discord timestamps explicitly show UTC.
  • Consistent line breaks: news, updates and other content tabs normalise Windows/Unix line endings and [br] markers.
  • Choose how feeds combine: merge local and Discord content, or show Discord posts with local content as the fallback when the remote feed is empty or disabled.

Make it your server’s hub

  • Configure the title, subtitle, accent colour, logo and window dimensions.
  • Enable the pages you need: welcome, news, updates, events, rules, server information, commands and community content.
  • Use Markdown or VTML for the main content. The additional content pages use VTML.
  • Choose join/show rules and whether players can use “Don’t show again”. Reopen the window with /motd.
  • Provide website, Discord or webmap links through the configurable buttons.
  • Connect optional Discord and Suite integrations for feeds and server information. These integrations need their corresponding services; the MOTD is a separate mod.

Writing news from the Suite webpanel

With the Suite and MOTD companion connected, open Community MOTD in the webpanel. Choose Announcements or Updates, enter a title, date and message in the post builder, then insert the post into your draft.

Use blank lines for paragraphs and start list lines with - or * for bullets. Check the preview, then choose Save & Apply. Inserting a post alone does not publish it.

The browser preview is an approximation. Check the finished result in game, especially if you use custom VTML, logos or live companion feeds.

Install & configure

  1. Install the MOTD ZIP on the server and participating clients. Use matching versions.
  2. Start the server to generate ModConfig/newfiescommunitymotd.json.
  3. Edit your content and enable the pages you want, or use the optional Suite editor.
  4. Use /motdreload to reload the configuration. Players can reopen it with /motd.

Administrator tools: /motdresetall resets the seen-state cache for clients. Server-control permission is required for reload/reset actions.

This build targets Vintage Story 1.22.7 / .NET 10. Keep a copy of your configuration before updating. Existing content is preserved rather than rewritten automatically.
